# safedrive-telemetria-ADAS
construção da lógica central para processamento de telemetria ADAS em C, utilizando matrizes bidimensionais.

# contextualização e objetivo

1

uma montadora precisa de um motor de decisão para o sistema ADAS (Advanced Driver Assistance
Systems) que processe um fluxo contínuo de dados de telemetria veicular. O sistema capta amostras
de sensores frontais e laterais, avalia o tempo de reação, calcula distâncias seguras de frenagem e
monitora as faixas de rodagem de forma dinâmica.

1.2

o objetivo deste projeto em laboratório é construir a lógica central desse sistema em Linguagem C,
implementando uma calculadora de telemetria acionada por um menu. O sistema deve armazenar e
processar múltiplas amostras de tempo (histórico de leituras) utilizando exclusivamente matrizes
bidimensionais.
